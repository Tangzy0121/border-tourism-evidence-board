# 边境旅游与特色农产品 · 公开情报看板

[打开共享看板](https://tangzy0121.github.io/border-tourism-evidence-board/)

全国市场调研大赛团队的公开资料查看入口。按研究问题呈现公开依据，说明资料可以怎样使用、适合写在哪一章，以及还需要补什么。

资料快照：2026-10-04。142条公开原页URL记录、55条指标、32篇历史核心文献、5类优先一手缺口。URL数不等于独立证据数，主题条数不表示市场规模。

## 使用

- 首页点击研究问题，可查看对应资料。
- 按关键词、地区、主题、核查状态、采用位置和年份筛选。
- 资料详情可打开原始来源；导出当前筛选CSV供讨论使用。
- 队友可直接查看，不需要账号。页面当前没有在线提交或多人实时编辑。发布更新后刷新页面即可查看。

## 公开范围

这里只包含公开来源元数据、团队整理的研究使用建议和页面素材。项目书、归档全文、内部讨论、访谈工具与个人信息没有发布到此项目；公开页面不连接私有项目文件。

研究使用建议不是原文直接结论。公开背景不能替代实际游客交易、旅后购买或供应结算，一手研究仍未完成。概念封面插画不是饶河实景照片或边界图。

## 维护

公开页面由内部项目的明确字段清单构建。维护者更新内部资料后重新生成并推送这里的页面，GitHub Pages自动发布。不要用整个内部项目覆盖此公开项目。
